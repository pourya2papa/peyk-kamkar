# پروژه اپ پیک (نسخه اولیه)

این بسته یک پروژه منبع Android با Kotlin است و هنوز فایل APK کامپایل‌شده نیست.

## امکانات نسخه نمایشی
- فهرست سفارش‌های نمونه و آدرس مشتری
- تغییر وضعیت سفارش
- باز کردن مسیریابی در Google Maps
- درخواست اجازه دسترسی موقعیت مکانی و نمایش مختصات فعلی هنگام استفاده از برنامه

## مواردی که برای نسخه عملیاتی لازم است
- سرور و پایگاه داده برای ارسال سفارش از پنل مدیریت به پیک‌ها
- ورود امن پیک و نقش‌های مدیر/پیک
- همگام‌سازی زنده سفارش‌ها و موقعیت مکانی
- سرویس مکان پس‌زمینه با اعلان دائمی و رعایت مجوزهای اندروید
- امضای نسخه Release و ساخت APK

## ساخت APK
این پروژه را در Android Studio باز کنید، اجازه دهید Gradle همگام شود و سپس از مسیر:
Build > Build Bundle(s) / APK(s) > Build APK(s)
خروجی Debug APK را بسازید.

برای توزیع عمومی یا عملیاتی، ابتدا سرور را پیاده‌سازی و تنظیمات Release را با کلید امضای خودتان انجام دهید.
